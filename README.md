# 🍳 Recipe Verse

**Recipe Verse** is an online recipe book website designed to make discovering, exploring, and preparing delicious recipes simple and enjoyable. It brings recipes together in one place with an easy-to-use and visually appealing interface.

## 🌐 About the Project

Recipe Verse is a web-based recipe platform where users can browse different recipes, explore ingredients and cooking instructions, and discover new dishes.

The project focuses on creating a clean, responsive, and user-friendly experience for anyone who loves cooking or wants to try something new.

## ✨ Features

* 🏠 **Home Page** – Attractive landing page introducing the recipe collection.
* 🍽️ **Recipe Collection** – Browse a variety of recipes.
* 🔍 **Recipe Search** – Quickly find recipes you're looking for.
* 📖 **Recipe Details** – View ingredients, cooking instructions, and recipe information.
* 🥗 **Recipe Categories** – Explore recipes based on different food categories.
* ❤️ **Easy to Explore** – Simple navigation for a smooth browsing experience.
* 📱 **Responsive Design** – Designed to work across different screen sizes.
* 🎨 **Clean & Interactive UI** – Modern interface focused on usability and visual appeal.

## 🛠️ Technologies Used

* **HTML5** – Used to create the structure and content of the website.
* **CSS3** – Used for styling, layout, animations, and responsive design.
* **JavaScript** – Used to add functionality and interactivity.
* **Web Browser** – Used to run and test the website.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone <your-repository-url>
```

### 2. Navigate to the Project

```bash
cd Recipe-Verse
```

### 3. Open the Website

Since Recipe Verse is built using HTML, CSS, and JavaScript, no additional dependencies are required.

Simply open:

```text
index.html
```

in your preferred web browser.

You can also use **VS Code with the Live Server extension** to run the website locally.

## 🍕 How to Use

1. Open the Recipe Verse website.
2. Browse the available recipes.
3. Explore different recipe categories.
4. Use the search functionality to find a specific recipe.
5. Select a recipe to view its details.
6. Check the ingredients and cooking instructions.
7. Follow the recipe and enjoy your meal! 👩‍🍳✨
